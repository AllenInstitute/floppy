### sheet: Concepts

Referential Integrity | In the context of relational databases, it requires that if a value of one attribute (column) of a relation (table) references a value of another attribute (either in the same or a different relation), then the referenced value must exist.
Row-level Security (RLS) | A database security feature that restricts data access at the row level based on a user's identity, role, or execution context.
Recursive Travel | An algorithmic method of visiting all nodes in a hierarchical data structure—like a tree or graph—by having a function call itself to process smaller sub-parts (subtrees) until it hits an endpoint.
ACID | Atomicity, Consistency, Isolation, and Durability. It is a set of rules for database transactions that make sure data stays safe, correct, and complete, even if the computer crashes or power fails.
WASM | WebAssembly
Transactional Outbox | Safely solves the dual-write problem in microservices. It ensures a service updates its local database and publishes an event to a message broker (like Kafka) atomically. Instead of publishing directly, the service saves the business data and an outbox event in the same local database transaction. A separate relay process then reads the outbox table and sends the messages.
