Interpretation
Only 11 top-level fields have a direct semantic destination. Direct mapping does not make the surrounding AIND object valid: 42 required or conditionally required target checks were assessed separately, and 28 are high-severity gaps. The dominant blockers are acquisition-level aggregation, cell-line/specimen identity, timing and device configuration, plate/well design, and missing administrative provenance.

### sheet: README

README and Method
How to interpret, audit, and update this workbook.
Workbook scope | AICS candidate schema 0.6.0 slim REMBI-categorized primary-image view compared with aind-data-schema v2.9.0.
Source shape | 33,184 rows; 186 top-level fields; four nested structures with 49 physical child fields.
Direct | Individual field meaning aligns. The surrounding AIND object may still lack other required fields.
Partial | A destination exists, but meaning, granularity, cardinality, or required context differs.
Extension container | Value can be retained in parameters/notes/additional settings without first-class semantics.
No first-class analog | AIND v2.9.0 lacks the scientific construct.
Platform or manifest | Belongs in a file inventory, storage/index service, lifecycle, or preview layer.
Derived/search-only | Flattened discovery field that should be regenerated from canonical nested values.
Required-gap inventory | Evaluates required and conditionally required AIND fields for an in-vitro imaging package; not a row-level completeness percentage.
Primary reference | https://github.com/AllenNeuralDynamics/aind-data-schema/tree/v2.9.0
Documentation | https://aind-data-schema.readthedocs.io/en/latest/
